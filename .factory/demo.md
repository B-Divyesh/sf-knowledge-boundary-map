# Demo sandbox

Open `/demo` or `/?demo=1` to use the causal-inference sample map. It contains three connected claims about correlation, confounders, and random assignment. One is marked Can explain, one Recognize only, and one Blocked. Each includes a realistic teach-back, boundary where relevant, next question, and rehearsal time.

The demo saves map changes and theme choice only in browser keys beginning with `demo:`. It never reads or changes your real map or theme. The persistent banner can reset the sample or discard it with **Start for real**. The home wordmark also discards the sample before opening `/`. Both exits restore your real map and theme.
