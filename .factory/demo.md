# Demo sandbox

Open `/demo` or `/?demo=1` to use the causal-inference sample map. It contains three connected claims about correlation, confounders, and random assignment.

The demo stores every map, rehearsal, theme, and license value under the `demo:` local-storage namespace. It never reads or writes the normal map namespace. The persistent banner can reset the sample or discard it with **Start for real**. Starting for real opens a blank private map and removes all demo storage.
